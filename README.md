# Light pollution sensor
This project is an IoT-based environmental monitoring system designed to raise awareness of light pollution and its impact on human health and urban environments. 
It combines multiple sensors with an ESP32 microcontroller to collect real-time data on light intensity, air quality, temperature, and humidity. 
The system processes this data, calculates a Blue Pollution Index (BPI), and makes the results accessible through both a web interface and the ThingSpeak cloud platform. 
Overall, the project demonstrates how technology can be used to better understand and address environmental challenges in a simple and cost-effective way.

**Key features of the project:**

* Real-time monitoring of light pollution using a colour sensor
* Measurement of temperature, humidity, and air quality
* Calculation of Blue Pollution Index (BPI) to assess blue light levels
* Web-based interface for live data viewing via ESP32
* Cloud integration using ThingSpeak for data storage and analysis
